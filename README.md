# ChemEasy
AI-powered chemistry learning and reagent information app

This app mainly focus organic chemistry and deals with most of reaction part and the main specific thing about 
this app is that if we enter any reactant or product or any catalyst it will give us all the information related 
to the concept and even it will help us to solve the reactions and create such flow charts of organic reactions 
which will help us to revise all the important reactions before the exams.
